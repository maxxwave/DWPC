# DWPC user manual

- **[dwpc_manual.pdf](dwpc_manual.pdf)**: the manual (physics, input keys, programs, verification, worked examples, reservoir-computing tasks).
- `dwpc_manual.tex` and `figures/`: LaTeX source. Build with `pdflatex dwpc_manual.tex` (run twice).
- `make_figures.py`, `scripts/`: the scripts that produced the figures from DWPC output files; `results.json` holds the numbers quoted in the text.
